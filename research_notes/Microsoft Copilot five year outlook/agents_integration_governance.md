## 1. What can Copilot Studio do today, and what do non-developers realistically build?

### Takeaway
By mid-2026 Copilot Studio has moved most headline agent capabilities to GA: computer use (13 May 2026), remote MCP servers and Agent2Agent (A2A) (about late May 2026), multi-agent orchestration, and one-click publishing to Teams/M365 Copilot (announced at Build, June 2026, for GA "next month"). A rebuilt "new Copilot Studio" authoring experience shown at Build 2026 is still in (production-ready) preview. Business analysts mostly build knowledge/Q&A agents and simple triggered workflows on top of connectors. Computer use, MCP, and multi-agent setups still need pro-maker or IT involvement in practice (this last point is inference).

## 2. Agent 365, Entra Agent ID, the agent registry/store, and Purview/Defender controls

### Takeaway
**Agent 365** was announced at Ignite (November 2025) as the "control plane for agents", previewed via the Frontier program, and **went GA on 1 May 2026 at $15/user/month** (also bundled in **Microsoft 365 E7, reported at $99/user/month**). It provides a registry, access control, visualization/analytics, interoperability and security for Microsoft and third-party agents. **Entra Agent ID** (announced in preview at Build 2025) gives each agent a first-class directory identity and reached GA around April/May 2026. Purview and Defender extend DLP, DSPM, audit and threat protection to agents, but several runtime-protection pieces were still preview in mid-2026.

### Cited Findings
**Agent 365**
- Announced at **Ignite 2025 (November 2025)** as a control plane for managing agents "whether they are created in Microsoft's ecosystem or from third-party partners" — [SD Times](https://sdtimes.com/net/microsoft-unveils-agent-365-a-unified-control-plane-for-agents/)
- Components: a **registry** ("single source of truth for all of an organization's agents"), **access controls**, a **unified dashboard/analytics** showing connections among agents, people and data, **interoperability** with apps and data, and **security** to detect, investigate and remediate attacks that target agents — [SD Times](https://sdtimes.com/net/microsoft-unveils-agent-365-a-unified-control-plane-for-agents/); [CRN Asia](https://www.crnasia.com/news-network/2025/microsoft-ignite-2025-the-biggest-news-in-ai)
- At Ignite it ingested agents built in Microsoft Foundry and Copilot Studio plus open-source and third-party partner agents — [WindowsForum Ignite 2025](https://windowsforum.com/threads/ignite-2025-copilot-becomes-an-agentic-platform-with-work-iq-and-agent-365.390199/)
- Preview access came through the **Frontier** early-access program. Admins enabled it in the M365 admin center under Copilot settings — [AdminDroid](https://blog.admindroid.com/microsoft-agent-365-unified-control-plane-to-manage-ai-agents/)
- **GA on 1 May 2026; standalone $15/user/month; included in Microsoft 365 E7.** E7 is reported at $99/user/month and combines M365 E5 + Copilot + Entra Suite + Agent 365 — [M365 Admin: Agent 365 becomes GA](https://m365admin.handsontek.net/microsoft-agent-365-becomes-generally-available-ga/); [Experts Exchange: What's M365 E7](https://www.experts-exchange.com/articles/40895/What-s-Microsoft-365-E7.html); [SAMexpert licensing](https://samexpert.com/agent-365/)

- **Registry:** the base "All agents" registry comes with the M365 admin center. Agent 365 adds the Risks column, the Security and Activity tabs, and Agent Map analytics. IT sees the registry in the M365 admin center, and security teams see the same data in Defender and Purview — [aguidetocloud Agent 365 security guide](https://www.aguidetocloud.com/blog/agent-365-security-governance-complete-guide/); [1security.ai registry explainer](https://1security.ai/en/use-cases/microsoft-365-agent-registry/)

**Entra Agent ID**

**Defender / Purview**
- **Defender:** network controls for Copilot Studio agents and local on-device agents shipped with the May 2026 GA. Broader Defender agent capabilities moved to public preview in June 2026. Another source says Defender coverage for agents completed a cutover on 1 July 2026 — [Secure in Seconds](https://www.secureinseconds.com/blog/2026-05-15-microsoft-agent-365-defender-stack); [Techzine](https://www.techzine.eu/news/security/139821/microsoft-secures-ai-agents-with-defender-entra-and-purview/)
- Runtime threat protection preview timing is inconsistent across sources (April vs June 2026). Security posture management for Foundry/Copilot Studio agents stayed in preview past Agent 365 GA — [nerdleveltech](https://nerdleveltech.com/microsoft-agent-365-ga-ai-agent-control-plane); [EPC Group Build 2026 governance](https://www.epcgroup.net/blog/microsoft-build-2026-agentic-governance-entra-purview-defender-agent-365-2026)
- **Purview** data protection applies to registered agents. One source says Purview in the Copilot Control System went GA in April 2026 — [aguidetocloud](https://www.aguidetocloud.com/blog/agent-365-security-governance-complete-guide/)
- **Oversharing:** agents inherit user permissions, so SharePoint-grounded agents "ruthlessly expose underlying oversharing". Microsoft's guidance recommends **SharePoint Advanced Management + Purview DSPM for AI** to detect and remediate oversharing before agents surface it — [Microsoft Q&A](https://learn.microsoft.com/en-us/answers/questions/5852075/what-governance-access-and-action-controls-can-we); [WindowsForum governance](https://windowsforum.com/news/microsoft-365-copilot-agent-governance-sharepoint-permissions-entra-ids-purview-auditing-and-roi.448294/)
- **Audit gaps:** the Purview Audit solution stores the transcript thread ID, not the conversation text. DSPM data risk assessments reportedly covered SharePoint/OneDrive only and not Dataverse knowledge sources, though another source says coverage has since extended to Dataverse-grounded agents — [PowerTricks runtime monitoring](https://www.powertricks.io/monitor-copilot-studio-agents-runtime/); [Exchange Anywhere: Purview DSPM 2026](https://www.anywherexchange.com/2026/08/microsoft-purview-dspm-in-2026-securing.html)
- **Org-split problem:** DSPM, Communication Compliance and Insider Risk Management are owned by compliance/security teams, not Power Platform admins, which splits responsibility — [PowerTricks governance reference](https://www.powertricks.io/copilot-studio-governance/)
- **Encryption:** Copilot Studio agents reportedly **cannot ground on content protected by encrypting sensitivity labels, DKE, or password protection** (secondary citing Learn) — [TechJack Solutions](https://techjacksolutions.com/ai-tools/microsoft-copilot/securing-copilot-studio-agents/)
- **Power Platform controls:** data policies can block unauthenticated publishing, and admins can set per-agent caps and viewer limits. Microsoft publishes an agent governance whitepaper — [Microsoft adoption: Administering and Governing Agents (PDF)](https://adoption.microsoft.com/files/copilot-studio/Agent-governance-whitepaper.pdf); [Atlan](https://atlan.com/know/ai-agent/ai-agent-applications/what-are-microsoft-copilot-studio-agents/)

### Inferences
- For IT and cautious leadership, the problems solved are: (a) **inventory/sprawl**, meaning which agents exist, who owns them and what they touch (registry plus Entra sponsors); (b) **identity and least privilege**, since agents get their own identities instead of piggybacking on app registrations or user tokens; (c) **data leakage**, via Purview DLP/DSPM, labels and audit; (d) **threat detection** with Defender (prompt injection, anomalous agent behavior). The E7 bundle signals that Microsoft intends to monetize governance per user, not per agent.
- Governance is maturing unevenly. Identity and registry are GA, while runtime protection, posture management and full audit fidelity were still preview or partial in mid-2026. Cautious organizations will likely gate autonomous and computer-use agents until those mature.

### Gaps
- Official Microsoft primary pages for Agent 365 GA pricing and the E7 price could not be fetched. Figures rest on partner/press sources that agree with each other, but one source contains a typo ("$991").
- The exact Entra Agent ID GA date (April vs 1 May 2026) is unresolved.
- No independent data was found on Agent 365 adoption. The "40 million registered agents" figure is a single secondary claim.

## 3. How Copilot connects to ERPs

### Takeaway
Microsoft offers five layers of ERP reach:
1. **First-party Dynamics 365 agents** (BC Sales Order/Payables agents GA in 2026 wave 1; F&SCM Account Reconciliation and Supplier Communications agents in production-ready preview, with conflicting GA reports).
2. The **Dynamics 365 ERP MCP server** (dynamic server PP Nov 2025 → GA reported Feb 2026 and/or 23 Sep 2026; static server retired 1 Oct 2026), now also feeding **Copilot Cowork** via a D365 ERP plugin.
3. **Copilot connectors** (synced or federated/MCP-based; federated GA April 2026) for knowledge.
4. **Power Platform premium connectors** (SAP, Oracle, etc.; 1,400+ connectors).
5. **Computer use** for browser-only or legacy ERPs.

Third-party ERP vendors increasingly expose their own agents and MCP/A2A endpoints (e.g., SAP Joule ↔ M365 Copilot).

### Inferences
- The preferred path for ERP access is shifting from bespoke connectors and APIs to **MCP**: Microsoft's own ERP (dynamic MCP server), federated Copilot connectors (MCP-based), and third-party ERPs exposing MCP/A2A. Copilot Studio and Cowork act as MCP clients. Computer use is the fallback for ERPs without APIs, and Citrix-hosted legacy ERPs remain a gap.
- For non-Microsoft mid-market ERPs (NetSuite, Epicor, Infor), the practical options as of Oct 2026 are Power Platform premium/custom connectors, vendor-provided MCP servers, or computer use. Specific vendor MCP availability was not verified.

## 6. Known limitations, costs, and failure modes

### Takeaway
Cost runs on **Copilot Credits** ($0.01 PAYG; $200 per 25,000-credit pack/month; generative answers about 2 credits; reasoning and tools cost more). Internal agents used by M365 Copilot-licensed users are largely covered, but autonomous and customer-facing agents always consume credits. Agent 365 adds $15/user/month (or E7). The main failure modes are oversharing exposed by agents, prompt injection/data exfiltration, agent sprawl, audit gaps, unsupported UI environments for computer use, credit exhaustion pausing agents, and the analyst-flagged risk that many agentic projects get canceled.

### Cited Findings
- **Pricing (third-party, consistent across sources):** Copilot Credits **$0.01 each PAYG** (billed via Azure). **$200/month capacity pack = 25,000 credits** (~$0.008/credit), pooled tenant-wide, with **no rollover**. The pack's billing cycle (monthly vs annual) conflicts across sources. Prepurchase commitments offer up to ~20% off. The maker license is free and running agents consumes credits. Classic answer = 1 credit, generative answer = 2 credits, and reasoning/tools cost more. Usage by M365 Copilot-licensed users of internal agents is generally not charged, while **customer-facing/autonomous agents always draw credits** — [CloudZero](https://www.cloudzero.com/blog/copilot-studio-pricing/); [Coworker.ai](https://coworker.ai/blog/copilot-studio-pricing); [Macha](https://www.getmacha.com/blog/copilot-studio-pricing-explained); [aguidetocloud licensing](https://www.aguidetocloud.com/licensing/copilot-studio/)
- **D365 agents on credits:** the BC Sales Order Agent pauses when credits run out — [Tigunia](https://tigunia.com/blog/business-central-ai-agents-controller-pre-flight-checklist/)
- **Agent 365:** $15/user/month standalone, or bundled in M365 E7 (reported $99/user/month) — [SAMexpert](https://samexpert.com/agent-365/)
- **Security failure modes:** a poisoned prompt can silently redirect outputs and leak PII without visible alerts or logs. Agents expose existing SharePoint oversharing. Audit stores thread IDs, not transcript text. Encrypted/DKE-labeled content can't be grounded — [TechJack Solutions](https://techjacksolutions.com/ai-tools/microsoft-copilot/securing-copilot-studio-agents/); [PowerTricks](https://www.powertricks.io/monitor-copilot-studio-agents-runtime/); [WindowsForum governance](https://windowsforum.com/news/microsoft-365-copilot-agent-governance-sharepoint-permissions-entra-ids-purview-auditing-and-roi.448294/)
- **Sprawl:** easy creation produces agent sprawl "faster than any manual review process can track" (vendor analysis) — [EPC Group](https://www.epcgroup.net/blog/copilot-studio-agent-governance-nine-controls-dependency-order-october-2026)

### Inferences
- Total cost of ownership for an autonomous ERP-facing agent includes Copilot Credits per run (unpredictable with reasoning models and computer use), Windows 365 Cloud PC capacity for computer use, Agent 365/E7 governance seats, and premium Power Platform licensing. Budget predictability is a real concern for cautious leadership, and credit exhaustion halting business processes is an operational risk.
- Readiness work (SharePoint permission cleanup, sensitivity labeling, DLP policies, agent sponsorship/ownership) is a prerequisite that often costs more than the agent build itself.
